Работа №1 — в [`hw1/`](hw1/). Основной файл: [`experiments.ipynb`](hw1/experiments.ipynb). Данные: Amazon Reviews 2018, Musical Instruments. Пять моделей реализованы самостоятельно: item-kNN, iALS, EASE, FM с брендом/категорией, ALS с кастомным целевым сигналом.

## Запуск

Python 3.12; CPU. Из корня репозитория:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r hw1/requirements.txt
cd hw1
python run_notebook.py
```

Скрипт выполняет ноутбук в текущем окружении и сохраняет ячейки с результатами. Первый запуск скачивает официальные отзывы и метаданные в `.cache/raw/`; следующие проверяют SHA256. Ручные ссылки и описание — в [`DATA.md`](hw1/DATA.md). Данные и окружение не загружаются в GitHub.

Настройки/пространства поиска: [`config.json`](hw1/config.json), seed=42, вычисления в один поток CPU. Временное разбиение, полный каталог кандидатов, исключение любых известных товаров, NDCG@10 как основная метрика и Recall@10 — одинаковы для всех моделей. Выбор настроек только на validation; затем переобучение на train + validation и финальная оценка на test.

Проверки формул ALS/EASE/FM, кастомного таргета, cosine similarity и протокола:

```bash
cd hw1
python -m unittest discover -s tests -v
```

Структура: `models/` — пять моделей; `data.py` — загрузка/подготовка; `evaluation.py` — общий ranking/метрики; `experiment.py` — подбор и финальный эксперимент. Таблицы и графики находятся в выполненном ноутбуке. При повторном запуске служебные результаты сохраняются только в игнорируемой `.cache/results/`.
